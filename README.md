# 🌸Random Quote Generator

A simple and responsive Random Quote Generator built with HTML, CSS, and JavaScript.

## Features

- Generates random quotes
- Displays the quote author
- Copy quote to clipboard
- Responsive design
- Simple and clean interface

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

- JavaScript arrays and objects
- Math.random()
- DOM manipulation
- Event listeners
- Clipboard API
- Responsive CSS

## How to Use

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Click **New Quote** to generate a new quote.
4. Click **Copy Quote** to copy the current quote.
